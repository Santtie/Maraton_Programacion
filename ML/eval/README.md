# Reportes de evaluación

`scripts/05_evaluate.py` escribe aquí un reporte (`.json` + `.md`) por cada corrida, con el
detalle caso por caso (`gold_cases.jsonl` + `adversarial_cases.jsonl`): si acertó las
palabras clave esperadas, si citó la norma esperada, y si reconoció correctamente los casos
fuera de dominio. Útil como evidencia para el reto extra E4 durante la demo.
